# Сервер Aion: утверждение постов и публикация в канал по расписанию

```
ноутбук (8:00): Claude -> JSON -> autopost\aion_daily.py --POST /batch (HTTPS, токен)--> сервер Aion
сервер:        сводка + карточка каждого поста с кнопками -> вам в бота
вы:            ✅ Опубликовать / ❌ Отклонить / 🚀 Сейчас
сервер:        утверждённые выходят в канал в слоты SLOTS (по одному на слот), карточка показывает ссылку
```

Устроено как `mother` из Marionette: Docker на том же VPS, база SQLite в `./data`, наружу только через общий
Caddy (`~/csd/Caddyfile`) по HTTPS. Ноутбук сам ходит на сервер, белый адрес ему не нужен.

## Кнопки

| Кнопка | Что делает |
|---|---|
| ✅ Опубликовать | ставит пост в ближайший свободный слот (после последнего слота дня — завтра в первый) |
| ❌ Отклонить | пост не выйдет; ↩️ Вернуть — снова ждёт решения |
| 🚀 Сейчас | публикует сразу |
| ↩️ Отменить | у утверждённого: снять из очереди, слот освобождается |
| 🔁 Повторить | если пост трижды не ушёл в канал |

Неутверждённый пост через `EXPIRE_HOURS` (24 ч) снимается («⌛ снят»), его можно вернуть.
Без вашего нажатия в канал не уходит ничего. `/status` в боте — очередь и счётчики.

После рестарта ничего не теряется: неотправленные карточки придут, пропущенный слот публикуется сразу при старте.

## Установка на сервер (31.76.46.113, пользователь arc)

1. Бот @aionspace_bot — администратор канала @aion_space с правом «Публикация сообщений».
2. Файлы: `scp -P 2222 -r server arc@31.76.46.113:~/aion` (без `.env` и `data`), на сервере
   `cp .env.example .env`, заполнить, `chmod 600 .env`. `AION_API_TOKEN`: `openssl rand -hex 32`.
3. В `~/csd/Caddyfile` добавить:
   ```
   aion.31-76-46-113.sslip.io {
   	reverse_proxy aion:8788
   }
   ```
4. Запуск (нужен sudo):
   ```bash
   cd ~/aion && sudo docker compose up -d --build
   cd ~/csd && sudo docker compose exec caddy caddy reload --config /etc/caddy/Caddyfile
   ```
5. Проверка: `curl https://aion.31-76-46-113.sslip.io/health` -> `{"ok": true}`.
6. Ноутбук: в `autopost\.env` вписать `AION_SERVER_URL=https://aion.31-76-46-113.sslip.io` и
   `AION_SERVER_TOKEN=<тот же AION_API_TOKEN>`, в `autopost\settings.json` — `"delivery": "server"`.

Журнал: `cd ~/aion && sudo docker compose logs -f`. Обновить код: залить файлы и `sudo docker compose up -d --build`.

**Один токен бота нельзя опрашивать из двух мест.** Кнопки слушает только сервер; не запускайте
`python bot.py` на ноутбуке, пока работает серверный. Ноутбук только шлёт сообщения об ошибках — это не мешает.
