# aionspace

Ежедневная подборка постов для Telegram-канала Aion Space.

| Папка | Что это |
|---|---|
| [`autopost/`](autopost/README.md) | ноутбук: в 8:00 Claude готовит посты (JSON), скрипт проверяет их и отправляет на сервер |
| [`server/`](server/README.md) | сервер: карточки на утверждение в боте, публикация в канал по расписанию (13, 15, 17, 21) |

Токены лежат только в `.env` (в git не попадают), образцы — в `.env.example`.
