# Aion Space autopost: утренняя подборка постов в бота Telegram

Каждый день в 8:00 (МСК) задача Планировщика Windows запускает цепочку (устроена так же, как автозапуск Marionette):

```
консольный Claude (claude -p, ваша подписка, только WebSearch и WebFetch) ищет свежие темы и пишет посты по prompt.txt
  → проверка: есть ли источник и подпись фото, домен картинки из списка открытых источников, нет ли повторов тем
  → скачивание картинок (большие сжимаются до лимита Telegram)
  → бот Telegram: фото + пост (жирный заголовок, отступы, подпись «Фото», ссылка «Источник», хештеги)
  → итоговая сводка (рубрики, страницы снимков, что сверено, идеи для видео, предупреждения)
  → журнал тем (history.json), чтобы темы не повторялись
```

Вы получаете в боте 3-4 готовых поста и выкладываете их вручную в течение дня.

## Один раз настроить

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → скопируйте токен.
2. **.env.** Скопируйте `.env.example` в `.env`, впишите `TELEGRAM_BOT_TOKEN`. Откройте своего бота и нажмите Start, затем запустите `chat_id.bat` и впишите показанный `TELEGRAM_CHAT_ID`. Токен никому не показывайте.
3. **Python-пакеты:** `pip install -r requirements.txt` (requests уже есть из Marionette; Pillow нужен, чтобы сжимать большие фото).
4. **Claude.** Консольный `claude` должен быть установлен и авторизован (`claude` → `/login`), как для описаний в Marionette. Если Claude недоступен напрямую, скрипт сам поднимает свой VPN из `Marionette\marionette\autostart\vpn` только на время этого шага (блок `vpn` в `settings.json`).
5. **Образцы стиля.** Вставьте 3-5 своих постов в `prompt.txt` на место `[СЮДА ВСТАВИТЬ ОБРАЗЦЫ ПОСТОВ]`.

## Проверка по шагам

| Файл | Что делает |
|---|---|
| `test_bot.bat` | одно тестовое сообщение в бота |
| `dry_run.bat` | Claude готовит посты, они печатаются в окне и сохраняются в `out\`, в Telegram ничего не уходит |
| `run_now.bat` | полный запуск: посты приходят в бота |

Когда всё работает: в PowerShell из этой папки `.\autostart.ps1 install`. Дальше `.\autostart.ps1 status` покажет состояние и хвост журнала.

## Настройки (`settings.json`)

| Поле | Значение |
|---|---|
| `run_time` | время запуска `HH:mm` (после изменения снова `install`) |
| `posts_per_day`, `min_posts` | сколько постов просить и сколько нужно минимум, чтобы день считался выполненным |
| `claude_model` | модель для подборки (по умолчанию `claude-sonnet-5-5`) |
| `claude_timeout_minutes`, `claude_attempts` | сколько ждать Claude и сколько раз пробовать |
| `image_domains` | домены, с которых разрешено брать картинки; остальные скрипт отклоняет |
| `send_digest` | присылать итоговую сводку |
| `vpn` | свой VPN для шага Claude и для Telegram (`mode`: `own` или `none`). Telegram сначала пробует `TELEGRAM_PROXY` из `.env`, затем напрямую, и только потом поднимает свой VPN |
| `wake_pc`, `fallback_after_minutes` | будить ПК из сна; второй запуск через столько минут, если первый пропущен (дважды за день посты не придут) |
| `sleep_after`, `sleep_only_if_idle_minutes` | после подборки усыпить ПК, если им не пользовались N минут |

## Как это работает в мелочах

- Фото в пост берётся только с доменов открытых источников (NASA, ESA/Webb, ESA/Hubble, ESO, JPL, Chandra). Подпись автора обязательна: без неё пост уходит текстом, без картинки, с пометкой.
- Если Claude не дал прямую ссылку на файл, скрипт находит картинку сам на странице снимка (`og:image`).
- Если текст с подписью длиннее 1024 знаков, в подписи к фото остаётся только заголовок, а полный текст приходит следующим сообщением.
- Если Telegram не принял разметку, пост уходит простым текстом.
- Токен бота в журналы не попадает.
- Повторный запуск в тот же день ничего не делает (выход с кодом 10). `-Force` или `run_now.bat` отправят подборку ещё раз.
- Журналы: `logs\daily_ГГГГ-ММ-ДД.log`. Ответ Claude и разобранные посты: `out\`.

## Чтобы ПК проснулся

То же, что для Marionette: ноутбук на зарядке и вечером в **сне** (не «Завершение работы»), таймеры пробуждения включены (`install` включает), вход в Windows сохраняется во сне. Не ставьте время Aion рядом со временем Marionette: оба используют один и тот же свой VPN, и одновременный запуск может его выключить.
